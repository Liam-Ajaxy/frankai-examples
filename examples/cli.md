   # frankai in your terminal

   Install (needs Node.js 20.3 or newer):

       npm install -g frankai
       frankai

   No install? Run it with npx:

       npx frankai

   ## Sign in

       frankai login

   Choose your browser, or paste a Terminal key from the developer console
   (https://developer.frankapi.workers.dev, then Keys, Create key, Terminal).

   ## Try these

       frankai explain recursion simply
       frankai summarize @notes.txt
       frankai draw a red bird on a branch
       frankai say Welcome to Kigali
       frankai me
       frankai doctor
